01 — Frontend (หน้าบ้าน) คืออะไร?

เปรียบเทียบในเกม RoV : เหมือน โมเดลตัวละคร 3D, สกินสุดเท่, เอฟเฟกต์แสงสกิล, หลอดเลือด HP และปุ่มกดสกิล 1-2-3 บนหน้าจอมือถือ ที่ตาเรามองเห็นและนิ้วสัมผัสกดปล่อยสกิลได้!
  • 01 สิ่งที่ตาเห็นในเกม : สกินตัวละคร Valhein, แสงเอฟเฟกต์อัลติเมต, ตัวเลขดาเมจ, มินิแมพ
  • 02 สิ่งที่นิ้วกดสั่งการ : ปุ่มเดินจอยสติ๊ก, ปุ่มกดใช้สกิล 1-2-3, ปุ่มซื้อไอเทมด่วน
  • 03 เครื่องมือสร้าง Frontend : HTML (วางโครงสร้างปุ่ม/รูป) + CSS (แต่งสกินสีสัน) + JS (แอนิเมชันขยับได้)

02 — Backend (หลังบ้าน) คืออะไร?

เปรียบเทียบในเกม RoV : เหมือน ระบบคำนวณดาเมจ, ระบบคูลดาวน์สกิล, กฎการแพ้-ชนะ และเซิร์ฟเวอร์เกม ที่คิดคำนวณอยู่เบื้องหลังตลอดเวลา!
  • 01 สมองกลคำนวณสด : พอยิงสกิล -> ติดคริติคอลไหม? โดนหักเกราะเท่าไหร่? เลือดศัตรูต้องลดกี่หน่วย? ติดสตั๊นกี่วินาที?
  • 02 ระบบป้องกันคนโกง : ป้องกันไม่ให้แฮกเกอร์แอบแก้เลือด แก้เงิน หรือเดินทะลุกำแพง
  • 03 ภาษาที่ใช้ทำ : Node.js (JavaScript หลังบ้าน), Python, C++, Go (รันบน Game Server)

03 — Database (ฐานข้อมูล) คืออะไร?

เปรียบเทียบในเกม RoV : เหมือน คลังเซฟไอดีผู้เล่น: สกินที่มี, รูนที่จัดไว้, แรงก์ (Conqueror), เหรียญทอง และประวัติการแข่ง ปิดเกมไปของก็ไม่หาย!
  • 01 เก็บข้อมูลไอดีถาวร : ต่อให้เปลี่ยนมือถือใหม่ ล็อกอินปุ๊บ สกินและแรงก์เดิมก็ยังอยู่ครบ 100%
  • 02 ค้นหาได้ทันที : ดึงประวัติการแข่งย้อนหลัง (Match History) และสถิติ Win Rate
  • 03 ระบบฐานข้อมูลยอดนิยม : PostgreSQL, MySQL, Supabase, SQLite, Redis

04 — Deployment (ออนไลน์สู่โลก) คืออะไร?

เปรียบเทียบในเกม RoV : เหมือน การปล่อยเกมลง App Store / Play Store และเปิด Server ให้ออนไลน์ทั่วประเทศ ให้ทุกคนกด "จับคู่ 5v5" เล่นด้วยกันได้!
  • 01 ถ้ายังไม่ Deploy : เหมือนผู้พัฒนาสร้างเกมเสร็จแต่นั่งเล่นคนเดียวในคอมฯ ตัวเอง เพื่อนโหลดไม่ได้ ชวนเล่น 5v5 ไม่ได้
  • 02 หลัง Deploy สำเร็จ : ตัวเว็บ/เกมจะขึ้นไปอยู่บน Cloud เซิร์ฟเวอร์ออนไลน์ 24 ชั่วโมง
  • 03 ได้ลิงก์ให้ทุกคนเข้าถึง : ส่งลิงก์ URL ให้เพื่อนทุกคนเปิดดูหน้าฮีโร่ของเราได้จากมือถือทันที
