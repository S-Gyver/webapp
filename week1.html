05 // เป้าหมายการเรียนรู้ประจำสัปดาห์ที่ 1 (วันที่ 1) กดปุ่ม ← ก่อนหน้า / ถัดไป → เพื่อเปลี่ยนสไลด์
กว่าจะเป็นเว็บได้ต้องมี 2 (+1) สิ่งนี้
HTML + CSS + (JS)
1. HTML (HyperText Markup Language) เปรียบเหมือน: โครงสร้าง
ใช้สร้างเค้าโครงเว็บและกำหนดว่าบนหน้าเว็บจะมีอะไรบ้าง เช่น หัวข้อ ข้อความ รูปภาพ ลิงก์ และปุ่มกด
2. CSS (Cascading Style Sheets) เปรียบเหมือน: เสื้อผ้า & สีสัน
ใช้ตกแต่งความสวยงาม กำหนดสี ขนาดตัวอักษร พื้นหลัง เส้นขอบ และจัดวางองค์ประกอบให้น่าใช้งาน
(3.) JS (JavaScript) เปรียบเหมือน: สมองสั่งงาน
ใช้เพิ่มการทำงานและการโต้ตอบให้หน้าเว็บมีชีวิตชีวา เช่น พอกดปุ่ม A แล้วให้แสดงชื่อหรือคำนวณแต้ม
ตัวอย่างหน้าเว็บ: HTML + CSS + JS
JS
การ์ดแนะนำตัว
นักเรียนชุมนุม Web Application
ครบทั้ง HTML + CSS + JS: หน้าเว็บสวยงาม และกดปุ่มโต้ตอบได้จริง!
คลิกที่ปุ่ม 1. มีแค่ HTML / 2. เติม +CSS / 3. เติม +JS เพื่อดูความแตกต่างของแต่ละภาษา กดปุ่ม ← ก่อนหน้า / ถัดไป → เพื่อเปลี่ยนสไลด์
